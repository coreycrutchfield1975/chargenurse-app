# ChargeNurse v6.3 — Provider Contact Coordination

Phase 15 makes provider contact information part of the appointment record.

## Scheduler
New editable fields:
- Provider Phone
- Provider Fax

When a configured Provider is selected, phone and fax fill only when those fields are blank. Staff may edit either value for a specific appointment.

## Travel Request
The Travel Request email preview and generated email now include:
- Provider
- Provider Phone
- Provider Fax

## Historical accuracy
Provider phone and fax are saved with the appointment. Later changes to Settings do not silently change previously saved appointment details.

## Preserved
- McCain and Cook defaults
- Editable master lists
- Flexible Provider entry
- Day, Week, Month, and Year views
- Travel Request safeguard
- Ticket to Ride
- Transportation status workflow
