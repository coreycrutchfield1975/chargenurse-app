# ChargeNurse v6.7 — Phase 19: Mission Control

## Command Center redesign

The Command Center now provides a clearer Mission Control view focused on what needs attention, what is scheduled next, what remains unfinished, and what has already gone well.

### Added

- Needs Attention panel with calm color-coded alerts and direct Scheduler links.
- Today’s Schedule grouped into Now, Next, and Later.
- Today’s Checklist using only `Complete` or the number remaining.
- Daily Wins generated from completed transportation, appointment, shower, vital, weight, and return workflows.
- Tasteful two-second confetti when a new Daily Win is earned.
- Quick Actions for commonly used ChargeNurse modules.
- Card entrance, hover, alert glow, checklist, schedule, and Daily Win animations.
- Reduced-motion support for workstations configured to minimize animation.

### Preserved

- Scheduler remains the owner of appointments and transportation.
- Veteran Records remains the owner of resident information and recurring schedules.
- Existing completion records and shared local data remain unchanged.
- Nursing Spark and rotating shift greetings remain available.
- Backup and restore remain available.

### Intentionally excluded

- AI features
- Workload scoring
- Percent-complete displays
- Unit Radar or timeline visualization
- Competitive rankings or staff scoring
