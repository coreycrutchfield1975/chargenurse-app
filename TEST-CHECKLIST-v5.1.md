1. Log in and open Command Center.
2. Confirm the Appointments tab displays upcoming appointments without edit controls.
3. Click **Open Full Scheduler**.
4. Create an appointment for an existing Veteran.
5. Return to Command Center and confirm the appointment appears.
6. Trigger a travel-related alert, then click **Open** in Alert Center.
7. Confirm Scheduler opens the correct appointment editor.
8. Edit and save the appointment in Scheduler.
9. Return to Command Center and confirm the updated status appears.
10. Confirm no external `clcscheduler.vercel.app` link remains.
11. Test desktop and mobile layouts.
12. Export a backup before production deployment.
