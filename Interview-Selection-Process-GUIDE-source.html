Interview Selection Process

A practical step-by-step guide to rubric setup, PBI scoring, Outlook handoff, and signed recommendations.

01
Set Up

Supervisor prepares rubric, applicants and questions

02
Distribute

Three individual forms go through Outlook

03
Evaluate

Panelists score independently and recommend

04
Return

Signed PDFs and completed forms go back

Workflow note. The current Outlook-only app still requires manual attachments. This guide documents those steps so no scoring information is lost.
Supervisor | Build the Position Rubric Steps 1–4
01
Open Rubric & Applicants

Select the Rubric & Applicants tab in the top navigation row.

02
Create a new position rubric

Select + New Position Rubric.

Enter a descriptive position name, such as Urgent Care RN.

Choose Next → Start with a blank rubric → Next.

03
Define the position-specific scoring criteria

Under Criterion 1, enter a job-related qualification (for example, RN Experience). Set the available points and, where appropriate, describe each scoring level (for example: 0 = no experience; 1 = 1–3 years).

If you leave score guidance blank, the app supplies generic 1–5 descriptions from Not adequate to Far exceeds.

Finish Review each criterion and select Save Rubric.

Tip: Use qualifications and scoring rules approved for the position. Confirm the point values before entering applicants.
04
Add and score all applicants against the rubric

Select + Add Applicant or + Add First Applicant. Enter the applicant name and interview date. Score the supervisor-established rubric criteria and add notes if needed.

Save Click Save Applicant; repeat until every applicant appears in the Rubric & Applicants list.

Tip: This is the rubric score. Individual PBI interview scores will be added later by the panelists.

Supervisor | Set Standardized PBI Questions Steps 5–6
05
Create or select the question set

Open Interview Questions and choose an applicant from the drop-down menu.

Create Select + New Set, enter a meaningful set name (for example, Urgent Care RN Interview), and click OK. You may also select an existing question set that is appropriate and approved for the position.

Tip: A new set may contain placeholder questions. Remove them with X or replace the final remaining placeholder with your first question.
06
Build, review, and save the PBI questions

Use + Add Q to type questions or PBI Library to select from the categorized question bank (more than 250 questions in the latest library). Review the order, wording, and number of questions. Use the same questions and rating scale for every applicant.

Finish Select Save Set and verify the final questions appear on screen.

Tip: Confirm the full question bank is loaded before choosing from the PBI Library.
Supervisor | Prepare Outlook Panelist Packets Steps 7–9
07
Open the panelist preparation window

Select Prepare 3 Panelist Forms in the top navigation row.

Enter the supervisor’s Outlook return email address and a unique name and Outlook address for each of the three panelists.

08
Lock questions and prepare the Outlook drafts

Select Lock Questions & Prepare Outlook Drafts. Confirm that the app shows the three Prepare Outlook Email + Form buttons. This step prepares the session; it does not send the emails.

Tip: Do not change the applicant list or PBI questions after forms are distributed. If changes are necessary, prepare and reissue a new session to all three panelists.
09
Send one form to each panelist

For Panelist 1, select Prepare Outlook Email + Form. The app downloads that panelist’s HTML form and opens an addressed Outlook draft.

Attach Manually add the newly downloaded HTML file to the matching Outlook email. Verify the recipient and attachment before sending.

Repeat separately for Panelists 2 and 3. Click Close when finished.

Tip: If VA Outlook blocks HTML attachments, stop and use an agency-approved alternative; do not bypass security controls.
Save a backup as you go. Your work saves automatically on this computer. To keep a copy — or to move the interview to another computer — open the Start tab and use Backup & Restore → Export. Use Import to reload a saved file. This is the only backup; the app has no shared drive or server.

INTERVIEW SELECTION PROCESS / USER GUIDE
Panelist | Open, Score, and Recommend Steps 1–7
Before you begin. Open the interview form only by an agency-permitted method. If the attachment is blocked or information is missing, contact the supervisor before proceeding.
01
Open your assigned interview form

Open the HTML interview form provided through Outlook using an approved browser or location. Each panelist receives an individual copy.

02
Verify your interview packet

Confirm the position, your panelist identity, and every applicant under Currently evaluating. Ensure the standardized PBI questions and supervisor-established matrix appear as expected.

03
Evaluate the first applicant

Select the first applicant in Currently evaluating. Review the PBI question, record factual interview notes, and select a score of 1–5 for every question. Use the established scoring guidance consistently.

Tip: Document job-related evidence from the responses. Avoid non-job-related or discriminatory considerations.
04
Complete all remaining applicants

Select Next Applicant and repeat the same process for every applicant. Check for missing scores before moving to your recommendation.

05
Record your independent recommendation

In My Independent Recommendation, select the applicant you recommend, or No Selection Recommended when appropriate. Your recommendation should consider the documented evidence and approved criteria, not numerical score alone.

06
Enter your job-related rationale

Explain why you recommend this applicant, citing specific job-related responses and evaluation criteria. This field is required before you can complete the evaluation.

07
Review and acknowledge your evaluation

Enter your name as the panelist and check the acknowledgement confirming that you completed and reviewed your own evaluation.

This typed acknowledgement identifies the reviewer; it is not an official electronic signature.

Panelist | Save, Sign, and Return Steps 8–10
08
Save and officially sign the evaluation PDF

Select Print / Save as PDF; choose Save as PDF or Microsoft Print to PDF in the print dialog. Open the resulting PDF and sign it using the VA-approved Adobe or agency signature procedure. Save the signed PDF in an approved location.

09
Save the completed HTML evaluation for score import

Select Save Completed Evaluation for Supervisor (.html). This completed file contains your scored answers and rationale. It is separate from the signed PDF and is needed for the supervisor to import your scores.

10
Prepare your Outlook return email

Select Prepare Outlook Return Email, then open the addressed draft to your supervisor. Attach BOTH (1) the signed PDF evaluation and (2) the completed evaluation HTML file. Verify the correct supervisor address, attachments, and applicant/session information; then send.

Tip: The app prepares the email but does not automatically attach either file.
Supervisor | Close Out the Interview After all three panelists respond
10
Import each completed evaluation

In the supervisor app, select Import Completed Evaluation in the top navigation row and choose each panelist’s completed HTML file. Repeat for all three panelists. Review the imported information and use Panel Recommendations to view individual recommendations.

Tip: Import from the original supervisor browser/profile used to prepare the session. A mismatch can prevent import.
11
Review, document, and retain the final record

Review all three independent evaluations, scores, job-related rationales, and separately signed PDFs. Document the panel’s final recommendation and complete the required agency approval and records process.

Final File Checklist

Each panelist returns 2 files: a signed PDF + completed HTML evaluation. The supervisor imports the HTML scores and retains the signed PDF according to approved records procedures.

IMPORTANT  This guide documents a prototype workflow, not an approved VA records or signing process. Test with fictional applicants until local HR, privacy, and IT/security requirements — including HTML attachments, storage, and e-signatures — are confirmed.
