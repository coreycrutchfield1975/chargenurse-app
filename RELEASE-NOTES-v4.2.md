# CLC Command Center v4.2 — Personal Appearance

## Added
- Appearance tab in Command Center.
- Three built-in default backgrounds.
- Upload a personal JPG, PNG, or WEBP directly from the user computer.
- Use project images stored under `backgrounds/custom/`.
- Adjustable overlay darkness, image fit, and image position.
- Selected background applies across Command Center, Morning Report, RN Workstation, Treatment Sheets, and login page.
- Personal uploads remain in browser local storage and are not uploaded to GitHub or Vercel.

## Privacy
Do not use images containing resident information or other PHI.
