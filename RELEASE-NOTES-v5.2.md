# ChargeNurse v5.2 — Shared Appearance System

## Added
- Appearance control available across all primary ChargeNurse pages.
- Built-in background gallery.
- Permanent project background support through `backgrounds/custom/`.
- Personal browser image uploads using JPG, PNG, or WEBP.
- Background preview.
- Dark overlay control.
- Panel opacity control.
- Image fit and position controls.
- Reset to each page's original default design.
- Legacy appearance setting migration from `clcAppearanceV1`.
- Privacy warning against using PHI in background images.

## Important behavior
- Selecting **Page Default** restores each module's own design and theme.
- Project images travel with the repository.
- Personal uploads stay only in the current browser.
