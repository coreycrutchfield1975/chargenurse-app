# ChargeNurse v6.1 — Shared Scheduler Dropdown Suggestions

Phase 13 expands the editable Settings master lists.

## Editable shared lists
- Providers
- Transportation
- Escorts
- Clinics
- Facilities
- Appointment Reasons

## Scheduler integration
The Scheduler now offers shared suggestions for:
- Provider
- Location / Destination
- Clinic
- Escort
- Transportation
- Travel Request Preparation / Appointment Reason

All fields remain editable. Staff may select a suggestion or type a custom value.

## Preserved workflows
- Day, Week, Month, and Year calendar views
- Travel Request email safeguard
- Ticket to Ride
- Transportation statuses
- Command Center deep links
- Existing appointment records
