# ChargeNurse / BravoShift

## Repository and deployment policy

- GitHub is the source of truth for this project.
- Make changes on a feature branch and merge them through a reviewed pull request.
- Use GitHub Pages for the static prototype and VA GitHub Enterprise for the approved VA copy.
- Do not add Vercel configuration, deployments, domains, or integrations.
- Do not place PHI or real Veteran information in the public repository, public GitHub Pages site, test fixtures, issues, pull requests, or build logs.
- Any future shared backend, database, identity integration, or PHI workflow must use a separately approved VA environment and security process. Its source and deployment workflow should still be managed from VA GitHub Enterprise.
