# CLC Command Center v4.1 Test Checklist

1. Sign in and confirm Command Center opens.
2. Open Calendar and verify the current month appears.
3. Add an appointment for an active resident.
4. Confirm the appointment appears on the calendar and selected-day agenda.
5. Open Transportation and confirm the new appointment has Ticket to Ride and Travel Request tracking.
6. Open Automation and confirm all four automations are active by default.
7. Select Run Now and confirm either updates are logged or the system reports it is current.
8. Add a test resident with recurring care days matching today.
9. Confirm those care items appear on Due Today and the Calendar.
10. Print the monthly calendar and confirm the print preview is readable.
11. Export a backup and confirm a JSON file downloads.
12. Refresh the browser and confirm residents, appointments, automation settings, and logs remain.
