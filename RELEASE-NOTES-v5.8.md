# ChargeNurse v5.8 — Connected Command Center

The Command Center now reads the shared Veteran, recurring schedule, appointment, Ticket to Ride, and Travel Request data.

## Focus
- Active census
- Showers due today
- Vitals due today
- Weights due today
- Appointments and transportation
- Items that still need attention

## Removed from this screen
- Duplicate Veteran admission editing
- Duplicate discharge controls
- Skin assessment task category
- Lab task category
- Independent Command Center roster logic

Veteran Records remains the owner of Veteran admission information and recurring schedules. Scheduler remains the owner of appointments, Travel Requests, Ticket to Ride, and transportation status.

## Preserved
- Due Today view
- Census
- Appointment feed
- Alert Center
- Printing
- Backup and restore
