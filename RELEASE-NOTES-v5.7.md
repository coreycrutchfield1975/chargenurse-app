# ChargeNurse v5.7 — Morning Report and Scheduler Connection

## Morning Report preserved
- All existing Morning Report sections remain.
- Shift assignments remain.
- Resident information and print layout remain.
- The report remains printable for team use.

## Appointment integration
- Scheduler is now the only appointment editor.
- Morning Report reads today's appointments from the shared ChargeNurse data layer.
- The appointment table still includes Veteran, leave time, appointment time, location, and with whom.
- Transportation status is now printed in the existing appointment table.
- Ticket to Ride readiness is shown when prepared.
- The Morning Report appointment button opens Scheduler for today's date.
- Duplicate manual appointment entry inside Morning Report is disabled.

## Transportation statuses shown
- Travel Request pending
- Travel Request sent
- Transportation confirmed
- Departed
- Returned / completed
- No transportation needed
- Ticket to Ride ready

No Morning Report content was removed to make this connection.
