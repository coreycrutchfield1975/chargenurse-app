# ChargeNurse v6.0 — Editable Provider List

## Provider terminology
The application uses the term **Provider**.

## Default providers
- McCain
- Cook

Chang has been removed from the default suggestions.

## Settings
A new Settings page allows authorized staff to:
- Add a provider
- Rename a provider
- Remove a provider
- Restore the McCain and Cook defaults

## Flexible entry
Provider fields are not locked dropdowns. They remain free-text fields with shared suggestions. Staff can select McCain or Cook, or type another provider when needed.

The shared provider suggestions are used by:
- Scheduler
- Veteran Records
- Morning Report

Removing a provider from Settings does not alter existing Veteran or appointment records.
