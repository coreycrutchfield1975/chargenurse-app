# CLC Command Center v4.0 Release Notes

## Major workflow additions
- Shift Briefing summarizes critical alerts, pending follow-up, daily work completion, and today's appointments.
- Operational Changes displays meaningful admissions, discharges, appointments, task completions, transportation updates, resident edits, and handoff saves from the last 36 hours.
- Shift Handoff provides focused Day and Night report fields designed to support the existing verbal report and printed report-sheet workflow.
- Printable Shift Handoff sheet includes remaining tasks, alerts, appointments, and signature lines.
- Persistent Alerts now support All, Critical, Pending, and Due Today filters.
- Daily task completion and reopening are recorded as operational changes.
- Admission, discharge, appointment, and transportation updates are recorded for the briefing.

## Existing capabilities retained
- One login session with automatic lock
- Resident Manager and admission expectations
- Full-removal discharge workflow
- Due Today and All Remaining checklists
- Transportation workflow including Ticket to Ride, Travel Request emailed status, confirmation, departure, return, missed transport, and chart flag
- Morning Report synchronization
- Resident search, profiles, and Room View
- Day and Night Shift Assignment Board
- Print Center
- Local backup and restore

## Removed
- Hermes Assistant is not included in this release.
